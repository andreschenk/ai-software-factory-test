# Issue-Entwürfe

Vorbereitete Issue-Folge für das Testprojekt (Benchmark). Sie werden erst als echte Issues angelegt, wenn die
Factory sie verarbeiten kann. `depends on: Issue NN` wird beim Anlegen durch `depends on #<nummer>` ersetzt.

| Nr | Titel | Prüft |
|---|---|---|
| 01 | Spring Boot einbinden | Änderung an `pom.xml` |
| 02 | Health-Endpunkt | Tests vorab |
| 03 | Produkte verwalten (CRUD) | grössere Umsetzung |
| 04 | Validierung und Fehlerantworten | Tests vorab, Fehlerfälle |
| 05 | Simulierte Fehler im Service | Konfiguration, Fehlerbehandlung |
| 06 | Suche und Paginierung | Grenzwerte |
| 07 | Rabatte | Rückfragepfad (absichtlich unvollständig) |
| 08 | Produktkategorien | `BLOCKED` durch Abhängigkeit |
